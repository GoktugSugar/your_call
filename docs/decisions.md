## 2026-07-09 — Localization system, and Turkish as the first added language (feat/localization-turkish)
Made the game fully localizable and shipped **Turkish** alongside English, as a plumbing-and-content pass over the existing systems (no gameplay rebuilt). English stays the default and every hard constraint holds in both languages (no dashes in any player-facing text, no fail state, no scoring or right answer, minimal UI, the profile silent, the imp's choice-independent mocking voice).
- **Approach: a lightweight overlay layer keyed by the English source string** (chosen over Unity's Localization package and over re-keying every asset). `Localization` (`Scripts/Localization/`, a static service) turns an English source string into the active language at the point it is shown. English is the source of truth and needs no file: its copy stays authored **inline** in the ScriptableObjects and scene beats exactly as before, so English reads byte-identical and gameplay wiring is undisturbed; a non-English language is one overlay file and `Localize` falls back to the English source for any missing key so nothing shows blank. (Trade-off, flagged and confirmed with the developer: the English copy lives in the data and scenes, not a file, but still flows through the layer at runtime. This kept the solo-authored Inspector workflow and minimised risk to a large, working content set.)
- **Localized at the shared display seams**, so beats and dilemmas needed no per-call changes: `NarratorView.Show`/`MeasureWrapped`, `ChoiceButtons.Present`, `StatsView`, `FloatingFigureText.Show`, the menu/settings/credits label setters, and the directly-drawn readouts (money total, country name/population, walking-button voice, three-track and would-you-rather option labels). Format strings localize the **template before** filling the `{0}` slots; the authored colour markup and placeholders travel inside each language's string. Party ids (`man`, `bear`, `charge`, routes) are never localized (internal matching keys).
- **Per-language files, one per language:** `Assets/Resources/Localization/<code>.json` (flat `k`/`v`/`area` entries, `JsonUtility`). Adding a language = drop `<code>.json` (same keys, translated) + one line in `Languages.All` (code, native name, .NET culture). **Numbers and currency** route through `Localization.Number`/`Money` (culture grouping; `$` kept, overridable via a `money.pattern` key).
- **Settings language option:** `GameSettings` holds the language in `PlayerPrefs` (`settings.language`) and drives the layer on boot; a `[RuntimeInitializeOnLoadMethod]` hook applies the saved language before any scene loads, so standalone/dev scenes respect it too. A new in-style **`OptionControl`** (Language row, a left/right cycler) switches language live; the menu and settings **re-localize on the fly** (`Relocalize` on each control). The settings panel frame was enlarged for the extra row (scene instance set explicitly).
- **Turkish font/glyphs:** the **Caveat** TMP asset is a **dynamic** atlas; the source carries the full Turkish set, and the Turkish characters were **pre-baked into the committed atlas** so they render with no missing glyphs, in the handwritten hand.
- **Turkish content: adapted, not literal.** The imp's voice and especially the **swearing** (the baby rage-quit, the one-dollar break, the shoot-the-imp ending, the walking button's yelp) were rewritten as idiomatic Turkish profanity carrying the same force and comedy, never literal translations of the English swears; no dashes. **This is a first pass and wants a native-speaker review** (see `open-questions.md`).
- **Reused, verified.** New `Localization`, `Languages`, `LocalizationData`, `OptionControl`, and `tr.json`; additive edits to `GameSettings`, `NarratorView`, `ChoiceButtons`, `StatsView`, `FloatingFigureText`, `CreditsRoll`, `MenuItem`, `MainMenu(Controller)`, `SettingsPanel`, `VolumeSlider`, `ToggleControl`, `InkButton`, `ThreeTrackConsequence`, `WouldYouRatherBeat`, `TimerButtonBeat`, `EscalatingOfferBeat`, `CancerNukeButtonBeat`, `WalkingButtonBeat`. Scripts compile clean (0 errors). Verified in play: an exporter confirmed **every** captured source string (20 dilemmas + all six scenes) has a matching `tr.json` key (only the brand title "Your Call" is intentionally left English); the menu, settings and opening narration render correctly in Turkish with **no missing glyphs**; the language setting switches all visible text live (en → tr → en); the boot hook applies Turkish in a scene with no `GameSettings`; and no console errors. The full click-through in each language is best felt in a real playthrough (the headless editor throttles the play loop). Updated `gameplay.md`, `art-and-ui.md`, `tech.md`, and `open-questions.md`.

## 2026-07-08 — Design pivot: from a moral trial to the imp's game of no-right-answer questions (feat/design-pivot-docs)
**A docs-only reframe. No gameplay code, scenes, prefabs, or assets changed** — only the markdown in `docs/` and `CLAUDE.md`. **This supersedes the earlier "moral trial" framing throughout:** where older entries or copy describe the game as a trial of the player's ethics, or as a moral-dilemma-only experience, this entry governs.
- **Frame: trial → the imp's game.** The afterlife is no longer a courtroom or a trial of the player's morality. It is the imp's game: he runs the player (still the dead judge, now the one being *figured out* rather than judged) through an ordered stream of questions to work out **who he is** — the whole person, not just his ethics. The irony is kept but reframed: the man who spent his life sizing up everyone else is now the one being sized up. The DUI stays a light recurring gag (unchanged). The payoff still points at the player: who *you* are, read through this character.
- **Content rule widened.** The only criterion for a question is that it has **no right answer** *and* it **divides people or reveals something about the answerer**. Dropped the "moral dilemmas only" framing: all question types are in scope (would-you-rathers, preferences, taste, absurd hypotheticals, confessions, and genuine dilemmas). Questions with an obvious consensus answer are cut, because the "how others chose" reveal is dead if everyone picks the same thing.
- **Mix: mostly light, heavy as spikes.** The light and medium questions are the volume; heavy dilemmas are rare, spaced spikes, paced in waves so a heavy one lands harder after a run of light ones. Tone stays dark comedy but playful: the imp gives the profound and the idiotic the same ceremony, and his single voice ties the range together.

## 2026-07-06 — Founding decisions (from initial design Q&A)
- **Platform / scope:** PC / Steam first; ~5–6 hours; linear campaign; ~25–35 dilemmas, each a full scene (~10 min).
- **Narrator:** recurring chaotic trickster who secretly tracks the player.

- **Audio:** text-first; VO later.
- **No fail state.**
