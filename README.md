# Your Call

A narrative dark comedy. You die. In a formless afterlife, a chaotic little imp runs you through his game of questions with no right answer, and quietly builds a portrait of who you really are.

Built in Godot 4.7 with GDScript, and being remade from scratch. Everything on screen is ink drawn in code on a paper ground.

## Running it

Open the folder in Godot 4.7 and press F5, or run `Godot --path .` from here.

## Where things are

- `docs/PREMISE.md`: the premise, the pillars and the design intent
- `docs/SCRIPT.md`: the content draft, every question and line in play order
- `docs/ARCHITECTURE.md`: how the game is built
- `docs/DECISIONS.md`: the dated decision log
- `docs/OPEN_QUESTIONS.md`: what is not settled yet
